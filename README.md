# Restaurant Analytics Dashboard

## Project Overview

An interactive Restaurant Analytics Dashboard developed using
Microsoft Power BI and DAX.

The project analyzes restaurant business performance,
customer behavior, restaurant performance, revenue, orders,
and delivery operations.

## Tools Used

- Microsoft Power BI
- DAX
- Power BI Data Modeling
- Data Visualization

## Dashboard Pages

1. Executive Overview
2. Customer Analytics
3. Restaurant Performance
4. Delivery and Operations
5. Advanced Insights
6. Restaurant Details

## Key KPIs

- Total Revenue
- Total Orders
- Average Order Value
- Average Delivery Time
- Total Customers
- Repeat Customer %
- Late Delivery %
- Cancellation %
- Revenue per Restaurant
- Average Rating
